# Plan to Implement Quote Creation Template for Admin in iRepair Ecommerce System

## Current State Analysis
The iRepair project has an admin panel for managing inventory (parts and services stock). To support wholesaler operations, we need to add a quote creation feature where admins can generate custom quotes for bulk orders or special pricing, which customers can then view or accept.

Existing system:
- Admin panel at `/admin` with stock management.
- Database schema with parts, services, orders.
- No existing quote functionality.

## Objectives
- Add a quote creation template in the admin panel.
- Allow admins to select parts/services, quantities, custom pricing, and generate quotes.
- Store quotes in database, link to customers if needed.
- Enable customers to view quotes (possibly via a dashboard or email link).
- Integrate with existing order flow if quote is accepted.

## Assumptions
- Quotes are for B2B/wholesale customers.
- Admins create quotes manually based on requests.
- Quotes include line items, totals, validity period.
- No automatic acceptance yet; manual process.

## Risk Assessment
- UI complexity for selecting items and pricing.
- Data integrity in quote storage.
- Integration with user system (if quotes tied to users).

## Implementation Plan

### Phase 0: Bug Fixes (1-2 days)
- Fix order_status enum: Add 'expired' back to enum (removed in migration 009), add pending → expired transition to order_state_transitions.
- Update worker's pollQueue.ts: Use transition_order_state RPC for checkout.session.expired handler instead of direct UPDATE.
- Fix refund handling: Route refund status change through transition_order_state RPC in charge.refunded handler, ensure validation and logging to order_state_history.

### Phase 1: Database Schema for Quotes (1 week)
- Create new tables: `quotes`, `quote_items`.
- Fields: quote id, customer info, items (part/service, qty, custom price), total, status (draft, sent, accepted, expired), validity date.
- Add migration to Supabase.

### Phase 2: Backend API for Quotes (1-2 weeks)
- Create API routes in Next.js for CRUD quotes.
- Functions: Create quote, update, list, send (email).
- Integrate with Supabase for storage.
- Add validation with Zod schemas.

### Phase 3: Admin UI for Quote Creation (2-3 weeks)
- Add "Quotes" section to admin panel.
- Template form: Select customer (if linked), add line items (search parts/services, qty, custom price).
- Calculate totals, add notes, set validity.
- Save as draft or send.
- List existing quotes with status.

### Phase 4: Customer-Side Quote Viewing (1-2 weeks)
- Add customer dashboard or page to view quotes.
- If quote accepted, convert to order (link to existing checkout).
- Email notifications for new quotes.

### Phase 5: Testing and Integration (1 week)
- Test quote creation, viewing, acceptance.
- Ensure compatibility with existing inventory/order system.
- Add unit tests, E2E if possible.

## Technologies
- Next.js for UI and API.
- Supabase for database.
- Email service (e.g., Resend or Supabase) for sending quotes.

## Evaluation of Completeness
This plan adds quote functionality to support wholesaler operations. It builds on existing admin panel and database. Completeness: Covers creation, storage, viewing, basic acceptance. Future enhancements: Automated quote generation, PDF exports.

## Dependencies
- Access to email service for notifications.
- UI design for quote forms.

## Metrics for Success
- Number of quotes created/viewed.
- Conversion rate from quote to order.</content>
